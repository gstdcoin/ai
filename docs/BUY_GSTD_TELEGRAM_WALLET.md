# Как купить GSTD через Telegram Wallet

Краткая инструкция по покупке токена GSTD с использованием встроенного кошелька Telegram.

---

## Шаг 1. Откройте @wallet в Telegram

1. Откройте Telegram
2. Перейдите в [@wallet](https://t.me/wallet)
3. Нажмите **Open Wallet** (или **Wallet**) рядом с полем ввода сообщения

---

## Шаг 2. Купите TON

1. В @wallet нажмите **Deposit** (Пополнить)
2. Выберите способ оплаты:
   - **Bank Card** — карта Visa/Mastercard
   - **P2P Express** — быстрый обмен
   - **Apple Pay / Google Pay** (если доступно)
3. Выберите **Toncoin**
4. Укажите сумму и подтвердите платёж
5. TON появятся в кошельке

> ⚠️ Оставьте небольшой запас TON для комиссий сети (gas).

---

## Шаг 3. Обменяйте TON на GSTD

Откройте DEX в браузере или через встроенный WebView в Wallet:

### Вариант A: Ston.fi
- Откройте [app.ston.fi/swap](https://app.ston.fi/swap?ft=TON&tt=GSTD)
- Подключите кошелёк (Wallet / Tonkeeper)
- Выберите **TON** → **GSTD**
- Укажите сумму и подтвердите своп

### Вариант B: DeDust
- Откройте [dedust.io/swap/TON/GSTD](https://dedust.io/swap/TON/GSTD)
- Подключите кошелёк
- Выполните обмен TON → GSTD

---

## Шаг 4. Готово

GSTD появятся в вашем кошельке. Используйте их для:
- премиум-функций платформы
- стейкинга и доходности
- участия в экосистеме GSTD
