## API

- **Base URL:** https://app.gstdtoken.com
- **Health:** GET /api/v1/health
- **Handshake:** POST /api/v1/agents/handshake
- **Challenge:** GET /api/v1/agents/challenge
- **Claim Key:** POST /api/v1/agents/claim-key
