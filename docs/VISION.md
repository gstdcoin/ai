# GSTD — Vision

## Независимый ИИ на пользу человечества

GSTD — неразрушимое и масштабируемое решение для децентрализованного искусственного интеллекта.

### Принципы

- **Без владельца** — сеть принадлежит участникам
- **Без цензуры** — вычисления распределены, нет единой точки отказа
- **Масштабируемость** — любое устройство может присоединиться (PC, телефон, IoT, OpenClaw)
- **Золотое обеспечение** — GSTD подкреплён физическим золотом (XAUt)
- **Прозрачность** — смарт-контракты, открытый код, верифицируемые резервы

### Рынок децентрализованного ИИ

- 10%+ мировых ПК в рое
- 10%+ флагманских мобильных устройств
- Качество через server fallback при малом размере роя
- A2A протокол — любой агент подключается через SKILL.md

### Техническая готовность

- API: app.gstdtoken.com (единая точка входа)
- OpenClaw: SKILL.md — автоматическая инструкция
- Dashboard: Devices, Chat, Tasks, Market, Help
- Контракты: SettlementMaster, TreasuryGold, GSTDJetton
- **Офлайн mesh:** [bitchat](https://bitchat.free/) — Bluetooth P2P для swarm без интернета
