# Настройка Telegram-бота для уведомлений

## Обзор

Telegram-бот отправляет уведомления о:
- 🆕 Создании новых задач
- ✅ Выполнении задач

## Создание бота

1. Откройте [@BotFather](https://t.me/botfather) в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям для создания бота
4. Сохраните полученный токен (например: `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`)

## Получение Chat ID

### Метод 1: Через бота @userinfobot
1. Откройте [@userinfobot](https://t.me/userinfobot)
2. Бот покажет ваш Chat ID

### Метод 2: Через API
1. Отправьте сообщение вашему боту
2. Выполните запрос:
   ```bash
   curl https://api.telegram.org/bot<YOUR_BOT_TOKEN>/getUpdates
   ```
3. Найдите `chat.id` в ответе

### Метод 3: Для групповых чатов
1. Добавьте бота в группу
2. Отправьте сообщение в группу
3. Выполните запрос `getUpdates` как выше
4. Найдите `chat.id` группы (отрицательное число)

## Настройка переменных окружения

Добавьте в `.env` файл:

```bash
# Telegram Bot Configuration
TELEGRAM_BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz
TELEGRAM_CHAT_ID=123456789
```

## Тонкий клиент и команды бота

### Команды (все пользователи)

| Команда | Описание |
|---------|----------|
| `/start` | Приветствие + кнопка «📱 Открыть приложение» (Web App) |
| `/help` | Справка и ссылка на полный дашборд |

### Команды (только админ, TELEGRAM_CHAT_ID)

| Команда | Описание |
|---------|----------|
| `/status` | Database, Contract, Sovereign AI |
| `/balance` | Escrow, количество пользователей |
| `/admin` | Панель с кнопками: Status, Balance, Pending Withdrawals |

### Web App (полный дашборд)

При нажатии «📱 Открыть приложение» открывается `https://app.gstdtoken.com` в Telegram WebView:
- TonConnect для авторизации через кошелёк
- Чат, майнинг, задачи, статистика
- Мобильный интерфейс (BottomNav)

### Переменные

```bash
APP_PUBLIC_URL=https://app.gstdtoken.com  # URL для Web App кнопки (опционально)
```

## Проверка работы

После настройки и перезапуска бэкенда:

1. Отправьте боту `/start` — должна появиться кнопка Web App
2. Нажмите «📱 Открыть приложение» — откроется дашборд
3. Подключите кошелёк и проверьте функционал
4. Если ваш Chat ID = TELEGRAM_CHAT_ID: `/admin` → кнопки управления

## Отключение уведомлений

Если не указать `TELEGRAM_BOT_TOKEN` или `TELEGRAM_CHAT_ID`, уведомления будут автоматически отключены (без ошибок).

## Troubleshooting

### Уведомления не приходят
1. Проверьте, что `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` установлены
2. Проверьте логи бэкенда на наличие ошибок
3. Убедитесь, что бот активен (отправьте `/start` боту)
4. Для групповых чатов убедитесь, что бот добавлен в группу

### Ошибка "Chat not found"
- Убедитесь, что вы отправили хотя бы одно сообщение боту
- Для групповых чатов убедитесь, что бот добавлен в группу

### Ошибка "Unauthorized"
- Проверьте правильность `TELEGRAM_BOT_TOKEN`
- Убедитесь, что токен не содержит лишних пробелов
