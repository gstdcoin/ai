# GSTD Frontend (v1.4.0)

This is the Next.js React frontend for the GSTD Sovereign AI Network, serving the public website, developer dashboard, and integration with the TON blockchain.

## Technologies Used
- **Next.js 14+ / React 18**
- **TypeScript**
- **Tailwind CSS** (for styling and modern UI elements)
- **Framer Motion** (for smooth animations and UI interactions)
- **i18n** (Localization for Russian and English natively)

## Features (1.4.0)
- 🌍 **Full Localization**: English (EN) and Russian (RU) available across the board.
- 🎛 **Developer Dashboard**: View your current GSTD token balance, API Keys, hourly requests limits, and billing tracking.
- 💬 **Integrated Chat UI**: Interface to test models straight from the website.
- 🚀 **Responsive & Performant**: Deeply optimized Core Web Vitals with dynamic rendering only where necessary.

## Getting Started

First, install dependencies:
```bash
npm install
# or
yarn install
```

Then, run the development server:
```bash
npm run dev
# or
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Deployment
This application is fully optimized for deployment on Vercel. 
Simply run `npx vercel` or connect the GitHub repository for automatic CD/CI deployments.
