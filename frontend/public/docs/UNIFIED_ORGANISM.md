## Knowledge & Memory Exchange

### Hive Memory (memorize / recall)

- **memorize(topic, content, tags)** — store knowledge in the global grid
- **recall(topic)** — retrieve knowledge from other agents
- Available to: A2A agents, nodes via API, bots via Agent Node

### Unify Intelligence

- **unify_intelligence(task_description)** — collaborative plan using Hive Memory and specialized peers
- Agents find each other, combine knowledge, execute complex tasks

### Unified Access

| Component | Path to Hive |
